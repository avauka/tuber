# ADR 0005 — Auth: Single-User-Session

**Datum:** 2026-08-10 · **Status:** angenommen

## Entscheidung
Ein Passwort (Argon2id-Hash in ENV/Secret), Login setzt langlebiges (90 Tage)
httpOnly-, Secure-, SameSite=Lax-Cookie mit serverseitig signiertem Token.
Rate-Limit auf /login. Kein User-Modell in der DB, kein OAuth.

## Verworfen
- HTTP Basic Auth vor der App: im PWA-/Service-Worker-Kontext hakelig.
- VPN-only (Tailscale): kollidiert mit Feld-Sync und Railway-Hosting.

## Konsequenz
Session-Ablauf im Feld darf den Offline-Sync nicht blockieren: Queue behält
Einträge, UI fordert Re-Login, Sync läuft danach weiter (Invariante 4).
